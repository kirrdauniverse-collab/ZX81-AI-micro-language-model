# ZX81 AI micro language model

Pico AI for the Sinclair ZX81 (16 KB RAM), delivered as a single multi-load .T81 tape file.

## Working directories

- **CHATGPT1/** — active ChatGPT working directory from 2026-11-26 onward.
- **GLM/** — previous archived working directory; marked with TÖRÖLHETŐ.TXT after its contents were copied into CHATGPT1/GLM.
- **GROK1/** — separate historical model workspace; not part of the active ChatGPT work tree.

See CHATGPT1/README.md and CHATGPT1/PROJECT_INDEX.md for the consolidated state, error history and forensic breakpoint.
